# 面板设计与交互（0.1.4 起）

> 这份文件是**动工前的定稿**。代码可以改，这里的决定要先改文档再改代码。
> 最后更新：2026-11-21

## 一、四条硬要求（用户明确）

1. **别的会话驾驶时，视口仍然允许看** —— 只读不等于遮住；可观测性是实验室的核心价值。
2. **右栏开始页的卡片要有图标**（现在那一格是空的）。用**自绘图标**（`icon.svg`：双层窗口 + 状态点），与右栏其它插件同一套线条语言，**不用 emoji**（2026-11-21 定：其它插件都不是 emoji，🧪 不合群）。
3. **会话头部不再注册入口** —— 那个「插件实验室」按钮去掉，只从右栏进入。
4. **智能体首次使用实验室时，右栏自动展开到实验室视口** —— 不用用户手动找。

## 二、版式：三带 + 抽屉

```
┌─────────────────────────────────────────┐
│ 插件实验室   ● 运行中 12:31  [会话 a1b2c3d4] │  头带
│ [▶ 启动]  [⋯]              :46000        │  主操作带
├─────────────────────────────────────────┤
│              iframe 视口                │  主体（吃满剩余高度）
├─────────────────────────────────────────┤
│ 🔒锁定   🤖未授权          日志 · 1 行 ▾ │  底带 + 抽屉把手
└─────────────────────────────────────────┘
```

- **头带**：名称 · 状态胶囊（运行中显示时长 `12:31`；崩溃显示「3 分钟前崩溃」）· 占用者 chip（短 id 前 8 位，`title` 给全 id）。
- **主操作带**：一个大按钮（启动 / 停止，按状态互斥）+ `⋯` 菜单（重启、刷新、弹出到窗口、切换版本、销毁）。销毁只在菜单里、红色、二次确认。
- **主体**：iframe 顶满；边框承载状态（运行中 success、崩溃 error、静止 neutral）。
- **底带**：`🔒 锁定` 与 `🤖 未授权` 两个 chip + 日志抽屉把手（默认收起，展开 140px，显示「日志 · N 行」）。
- 原底部常驻的「隔离说明」收进 `⋯ → 关于隔离边界`；锁定态徽章自带那句免责。

## 三、占用（会话级面板 × 全局实验室）

| 情况 | 头带 chip | 主操作 | 视口 |
|---|---|---|---|
| 本会话驾驶 | `本会话`（brand） | 启动/停止 + ⋯ | 可点 |
| 别的会话驾驶 | `会话 a1b2c3d4 · 18:20 起`（灰） | 只留 `接手` | **仍给看**，锁定遮罩常开 |
| 无人驾驶 | `空闲` | 启动 + ⋯ | 未运行则占位卡 |
| 自己驾驶但崩了 | `本会话` + 红胶囊 | `重启` | 错误说明卡 |

**claim 时机：动手才 claim**（启动 / 停止 / 接手 / 授权 agent / 派活时），打开面板不占坑。
撞 409 时，错误条显示宿主的拒绝文案（带占用者标题与 id），同时主按钮已经是「接手」；接手在实验室运行中时加一句「会中断对方正在进行的操作」。
**占用者显示会话标题**，与左侧栏列表逐字一致：`启动 plugin_lab 实验 · 18:20 起`。
标题随对话实时变（官方 session-titles 插件按全部消息重算），解析有两层：
面板用槽位标准 prop `useSessions` 的 `byId[id].title`（左侧栏渲染的就是这份，覆盖全部会话）；
拿不到再退回 `/state` 带回的 `ownerTitle`（宿主侧，只能解析**正在跑**的会话）；都没有才显示 id 前 8 位。

## 四、自动展开（要求 4）

- 客户端半在**插件加载时**就建立**一条** SSE 长连接（现在只有面板挂载时才连，要改成页级单例），面板订阅它。
- 宿主 `plugin_lab` 的驱动类动作（start / restart / ui / dispatch）成功后广播 `{ type: 'open-lab', id }`。
- 客户端收到后：`ctx.sidebarRight.openTab(kind)` → 失败再 `ctx.layout.openRightbar(true, false)`。
- 每个会话只自动展开一次（记在内存里），避免 agent 连续调用时反复抢焦点。

## 七、待办（按优先级）

### 1. 内嵌视口的主机名不一致（0.1.4 缺陷，0.1.5 已修）

症状：桌面版面板里 iframe 停在 `dsh web authentication required; reopen the URL printed by dsh web.`

**已确认的机制**（`localhost` / `127.0.0.1` 两个页面 iframe 同一个实验室，A/B 对照）：

- 实验室的登录是 `?token=` → **303** + `Set-Cookie: dsh-auth-<token 哈希>=…; HttpOnly; SameSite=Strict` → 再请求 `/`。
  curl 不带 cookie jar 时照样 401 —— 换成 cookie 这一步是必需的；
- 页面在 `127.0.0.1:8099`、实验室在 `127.0.0.1:46000` → **正常显示**；
- 页面在 `localhost:8099`、实验室在 `127.0.0.1:46000` → **退回鉴权页**。
  两者不同站，`SameSite=Strict` 的 cookie 在 iframe 里存不下；
- 实验室**不校验 `Host`**（`localhost:46000` 与 `127.0.0.1:46000` 都回 303），所以换主机名没有副作用。

**修法**：`/frame` 的 302 用本次请求的 `Host` 主机名替换实验室地址的主机名，让 iframe 与宿主页面同站。
验证走同一条 A/B：页面用 `localhost` 打开宿主、面板里实验室正常渲染。
